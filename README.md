## Вступительные задания

| № | Файл | Что делает | Темы |

| 2 | [Ex2.py](<Вступительные задания/Ex2.py>) | Считает евклидову норму, нормализует векторы, находит скалярное произведение и косинусное расстояние | функции, векторы, обработка ошибок |
| 3 | [Ex3.py](<Вступительные задания/Ex3.py>) | Считает разницу между датами в днях | даты, строки, проверка формата |
| 4 | [Ex4.py](<Вступительные задания/Ex4.py>) | Реализует стек на односвязном списке: `push`, `pop`, `peek`, `is_empty`, `len` | классы, ссылки, структуры данных |

Пример результата `Ex1.py` для [1, 2, 5, 7, 9, 32, 5, 7, 13, 7, 996, 9]:

```text

```

## Домашнее задание

[module_1.ipynb](<homeworks/module_1.ipynb>) — 20 задач по датасету бейсбольных матчей:

- загрузка, очистка и форматирование данных;
- поиск игр по максимальным и минимальным показателям: посещаемость, температура, длительность, ветер, очки, ошибки, хиты;
- количество игр и побед для каждой команды;
- связь посещаемости и побед;
- анализ матчей по дням недели и по температуре.

Ноутбук содержит код, пояснения и сохранённые выводы. Датасет `baseball_games.csv` лежит рядом с ноутбуком.

## Как запустить

Нужен Python 3.10 или новее.

```bash
pip install -r requirements.txt
```

Вступительные задания:

```bash
python "Вступительные задания/Ex1.py"
python "Вступительные задания/Ex2.py"
python "Вступительные задания/Ex3.py"
python "Вступительные задания/Ex4.py"
python "Вступительные задания/Ex5.py"
```

Ноутбук:

```bash
jupyter notebook "homeworks/module_1.ipynb"
```

Запускай ноутбук из папки `homeworks` или открывай через Jupyter: он читает `baseball_games.csv` по относительному пути.

## Как проверять

- Каждый файл `Ex*.py` запускается отдельно; в конце файла есть демонстрационный пример.
- `Ex2.py` сразу показывает несколько случаев: корректный расчёт, разные размерности, пустой и нулевой векторы, нечисловые элементы.
- В ноутбуке видно и решение, и пояснения, и результат выполнения каждой ячейки.
